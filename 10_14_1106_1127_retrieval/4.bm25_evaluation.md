# BM25 검색 평가 · 정답지 확인과 동의어 적용

## 1. 기본 검색을 원래 정답지로 채점하기

3번 자료 2절의 첫 검색을 실행합니다. 문단 1,000건을 색인한 `rag-miracl-ko-bm25`에서 `korean_text` 분석기로 제목과 본문을 검색합니다. [3번 BM25 검색 실습](3.bm25_search.md#2-제목과-본문-검색)

```json
GET /rag-miracl-ko-bm25/_search
{
  "size": 10,
  "_source": ["title", "text"],
  "query": {
    "multi_match": {
      "query": "혼다 미나코의 출생 병원은 어디인가요?",
      "fields": ["title", "text"],
      "analyzer": "korean_text"
    }
  }
}
```

질문 파일에서 이 질문의 ID인 `1192`를 찾습니다. 정답지에서 같은 `query_id`의 줄을 읽고, 검색 결과의 `_id`와 정답지의 `docid`를 맞춥니다. [질문 파일](dataset/queries.jsonl) · [정답지](dataset/qrels.jsonl)

관련도 1인 문단이 처음 나오는 순위를 적습니다. 3번 자료의 기본 검색 예시에서는 `64649#0`이 1위이고, 원래 정답지에서 관련도 1을 받은 문단도 `64649#0`입니다. 따라서 이 정답지로 채점하면 정답 문단이 **1위**에 나온 것으로 기록됩니다.

## 2. 본문을 읽고 관련도 다시 판정하기

검색 결과에서 1위와 5위 문단의 `_source.text`를 읽습니다. 출생 병원의 이름이 어느 문단에 적혀 있는지 확인합니다.

| 기본 검색 예시의 순위 | 문단 ID | 본문에서 확인한 내용 | 원래 관련도 | 실습에서 다시 매긴 관련도 |
| ---: | --- | --- | ---: | ---: |
| 1위 | `64649#0` | 인물 소개와 생몰 연도 | 1 | 0 |
| 5위 | `64649#3` | 나리마스 산원에서 태어났다는 설명 | 0 | 1 |

내 실습 폴더의 `dataset/qrels.jsonl`에서 질문 `1192`의 두 줄을 다음과 같이 수정합니다.

```jsonl
{"query_id": "1192", "docid": "64649#0", "relevance": 0}
{"query_id": "1192", "docid": "64649#3", "relevance": 1}
```

## 3. 같은 검색 결과를 다시 채점하기

1절의 검색 결과를 수정한 정답지로 다시 채점합니다. 검색 결과는 그대로이고, 관련도 1인 문단이 처음 나오는 순위는 **1위에서 5위**로 바뀝니다. 이제 5위의 `64649#3`이 기본 검색에서 확인한 정답 순위입니다.

## 4. 동의어를 적용하고 정답 순위 비교하기

1절의 요청에서 `analyzer`만 `korean_search_synonyms`로 바꿔 다시 검색합니다. `병원`과 함께 `산원`도 검색되도록 3번 자료에서 등록한 동의어 규칙을 사용합니다. [동의어 적용 실습](3.bm25_search.md#3-동의어-적용-전후-비교)

수정한 정답지로 두 검색 결과를 채점해 `64649#3`의 순위를 비교합니다. 3번 자료의 실행 예시에서는 기본 검색 **5위**에서 동의어 적용 검색 **4위**로 한 계단 올라갑니다.

## Python으로 같은 순서 확인하기

스크립트의 검색 요청 본문을 1절의 요청과 맞춥니다. `analyzer`는 `korean_text`로 설정하고 `multi_match`에 `type`이 있으면 지웁니다. 학생용 저장소 루트에서 아래 명령을 실행해 정답 순위를 적습니다. 2절에 따라 `dataset/qrels.jsonl`을 수정한 뒤, 같은 명령을 다시 실행해 순위를 확인합니다. [순위 확인 스크립트](4.evaluate_bm25.py)

```powershell
uv run --python 3.12 --with 'elasticsearch>=8.19,<9' python ./10_14_1106_1127_retrieval/4.evaluate_bm25.py
```

마지막에는 스크립트의 검색 요청 본문에서 `"analyzer": "korean_text"`를 `"analyzer": "korean_search_synonyms"`로 바꾸고 같은 명령을 다시 실행합니다.

## 정답 순위를 평가 지표로 확인하기

정답지 수정과 순위 확인을 마친 뒤, 학생용 저장소 루트에서 지표 계산 스크립트를 실행합니다. 첫 실행은 `korean_text`로 검색합니다. 다음 실행에서는 요청 본문의 `analyzer`만 `korean_search_synonyms`로 바꿉니다. [지표 계산 스크립트](4.bm25_metrics.py)

```powershell
uv run --python 3.12 --with 'elasticsearch>=8.19,<9' python ./10_14_1106_1127_retrieval/4.bm25_metrics.py
```

스크립트는 정답 순위 아래에 Recall@10, RR@10, nDCG@10을 출력합니다. Recall은 정답 문단 중 상위 10건에 들어온 비율입니다. RR은 첫 정답 순위의 역수이고, MRR은 여러 질문의 RR을 평균한 값입니다. nDCG는 관련 문단이 상위에 나올수록 높아집니다. [검색 평가 지표](0.retrieval_intro.md)

수정한 정답지로 3번 자료의 검색 예시를 채점하면 다음과 같습니다.

| 검색 | 정답 순위 | Recall@10 | RR@10 | nDCG@10 |
| --- | ---: | ---: | ---: | ---: |
| 기본 검색 | 5위 | 1.0000 | 0.2000 | 0.3869 |
| 동의어 적용 | 4위 | 1.0000 | 0.2500 | 0.4307 |

두 검색 모두 유일한 정답 문단을 상위 10건에서 찾았으므로 Recall@10은 1입니다. 동의어 검색에서는 정답 문단이 한 계단 올라 RR@10과 nDCG@10도 높아집니다.
