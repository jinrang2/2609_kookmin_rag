# 7강: RRF로 BM25와 kNN 검색 결과 합치기

## 1. BM25로 검색하기

```http
POST /rag-miracl-ko-bm25/_search
{
  "size": 10,
  "_source": ["title", "text"],
  "query": {
    "multi_match": {
      "query": "혼다 미나코의 출생 병원은 어디인가요?",
      "fields": ["title", "text"],
      "analyzer": "korean_text"
    }
  }
}
```

## 2. 같은 질문으로 kNN 검색하기

  -   제목과 본문을 함께 임베딩한 `rag-miracl-ko-bge-m3-title-body` 인덱스에서 상위 10개를 가져옵니다.
  - `k`와 `size`를 10으로 설정해 BM25와 같은 개수의 후보를 수집합니다.

```python
body = {
    "size": 10,
    "_source": ["title", "text"],
    "knn": {
        "field": "embedding",
        "query_vector": question_vector,
        "k": 10,
        "num_candidates": 50,
    },
}
response = client.search(index="rag-miracl-ko-bge-m3-title-body", body=body)
knn_hits = response["hits"]["hits"]
```

질문 임베딩과 Elasticsearch 접속을 포함한 전체 예제는 [7.rrf.py](7.rrf.py)에 있습니다.

## 3. RRF로 두 검색 결과 합치기

  - RRF(Reciprocal Rank Fusion)는 문서의 순위를 `1 / (60 + 순위)`로 바꿔서 더합니다.
  - 한 목록에 문서가 없으면 그 목록의 점수는 0입니다.
  - 합계가 높은 문서로 내림차순 정렬합니다

| 문서 | BM25 순위 | kNN 순위 | RRF 점수 계산 | 점수 |
| --- | ---: | ---: | --- | ---: |
| A | 1위 | Top 10 밖 | `1/61 + 0` | 0.016393 |
| B | 2위 | 3위 | `1/62 + 1/63` | 0.032002 |
| C | 3위 | 1위 | `1/63 + 1/61` | 0.032266 |

**실행 명령어**

```shell
uv run --env-file .env --python 3.12 --with requests --with "elasticsearch>=8.19,<9" python ./10_14_1106_1127_retrieval/7.rrf.py
```

| 질문 | BM25 근거 청크 순위 | kNN 근거 청크 순위 | RRF 근거 청크 순위 |
| --- | --- | --- | --- |
| 혼다 미나코의 출생 병원은 어디인가요? | 5위 | 1위 | 2위 |

세 결과에서 `64649#3`의 순위를 기록하고, 그 청크의 RRF 점수를 BM25 순위와 kNN 순위로 각각 계산한 점수를 더해 확인합니다.

## 6. 가중치 RRF로 검색의 비중 바꾸기

가중치 RRF(Weighted RRF)는 각 검색의 순위로 계산한 점수에 가중치를 곱한 뒤 더합니다. 7강 코드는 기본값으로 BM25와 kNN에 각각 1을 사용합니다. kNN 가중치를 높이면 kNN 순위가 최종 RRF 점수에 더 크게 반영됩니다. [Elasticsearch 가중치 RRF 설명](https://www.elastic.co/search-labs/blog/weighted-reciprocal-rank-fusion-rrf/)

```text
가중치 RRF 점수 = BM25 가중치 / (60 + BM25 순위) + kNN 가중치 / (60 + kNN 순위)
```

**“혼다 미나코의 출생 병원은 어디인가요?”**를 다시 검색합니다. 질문과 검색 설정을 그대로 두고, BM25 가중치를 0.2, kNN 가중치를 0.8로 지정합니다.

**실행 명령어**

```shell
uv run --env-file .env --python 3.12 --with requests --with "elasticsearch>=8.19,<9" python ./10_14_1106_1127_retrieval/7.rrf.py --bm25-weight 0.2 --knn-weight 0.8
```

| 청크 | BM25 순위 | kNN 순위 | 기본 RRF 순위 | 가중치 RRF 점수 | 가중치 RRF 순위 |
| --- | ---: | ---: | ---: | --- | ---: |
| `64649#3` 출생 병원 | 5위 | 1위 | 2위 | `0.2 / 65 + 0.8 / 61 ≈ 0.016192` | 1위 |
| `64649#0` 인물 소개 | 1위 | 2위 | 1위 | `0.2 / 61 + 0.8 / 62 ≈ 0.016182` | 2위 |

가중치를 BM25 0.25, kNN 0.75로 바꿔 다시 실행하면 인물 소개 청크가 1위입니다. 두 설정에서 점수를 계산해 순위가 바뀌는 이유를 확인합니다.

## 7. 마지막으로 통합 후보 리랭킹하기

### 질문에 맞게 후보 문서 재정렬하기

`query`에 질문을, `documents`에 후보 문서를 넣습니다. `bge-reranker-v2-m3`는 질문과 각 후보의 관련도를 매기고, `top_n`에 지정한 개수만큼 결과를 반환합니다. 세 문장 중 어떤 두 문장이 돌아오고 서울이 나오는 문장이 몇 위인지 확인합니다.

관련도 점수에 sigmoid를 적용하면 0과 1 사이의 값으로 바뀝니다.

파일명은 `7.rerank.py`입니다.

```python
import os

import requests

base_url = "https://labiv-llm.z.cs.kookmin.ac.kr"
ID = os.environ["LABIV_API_ID"]
PASSWORD = os.environ["LABIV_API_PASSWORD"]

path = "/v1/rerank"
payload = {
    "model": "bge-reranker-v2-m3",
    "query": "대한민국의 수도는 어디인가?",
    "documents": [
      "서울은 대한민국의 수도이다.",
      "파리는 프랑스의 수도이다.",
      "고양이는 포유류이다."
    ],
    "top_n": 2,
}

response = requests.post(
    f"{base_url}{path}", auth=(ID, PASSWORD), json=payload, timeout=60
)
response.raise_for_status()
print(response.json())
```

**실행 명령어**

```shell
uv run --env-file .env --python 3.12 --with requests python ./10_14_1106_1127_retrieval/7.rerank.py
```
