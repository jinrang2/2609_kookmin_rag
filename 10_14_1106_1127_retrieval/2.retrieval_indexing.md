# 10주차 · 검색용 문서 색인

[Retrieval 개론](0.retrieval_intro.md)에서 본 색인 단계를 진행합니다. 먼저 Kibana에서 문단 한 건을 넣으며 매핑과 문서 ID를 확인합니다. 이어 Python으로 한국어 문단을 임베딩하고, 텍스트·벡터·출처를 같은 Elasticsearch 문서에 저장합니다.

```mermaid
flowchart LR
    P["MIRACL 문단"] --> M["문단 ID · 제목 · 본문 · 출처"]
    M --> E["본문 임베딩 · 384차원"]
    M --> I[("Elasticsearch")]
    E --> I
    I --> V["문서 수 · 매핑 · 저장된 문단 확인"]
```

## 1. 데이터와 색인 단위

공통 데이터는 MIRACL 한국어 소규모 평가셋의 [corpus.jsonl](dataset/corpus.jsonl)입니다. 원본 위키백과의 문단 1,000개가 한 줄에 하나씩 들어 있습니다. 이미 문단 단위로 나뉘어 있어, 이번 색인에서는 **JSONL 한 줄을 검색할 청크 한 건**으로 사용합니다.

| 필드 | Elasticsearch 타입 | 용도 |
| --- | --- | --- |
| `docid` | `keyword` | 원본 문단 ID. Elasticsearch의 `_id`에도 같은 값을 사용합니다. |
| `chunk_index` | `integer` | 원본 문서 안에서의 0부터 시작하는 문단 번호. `1870732#1`이면 `1`입니다. |
| `title` | `text` | 원문 제목 |
| `text` | `text` | 검색할 문단 본문 |
| `source` | `keyword` | 데이터 출처 |
| `topic` | `keyword` | 주제 패싯. 예를 들어 역사·정치, 과학·기술, 문화·스포츠 |
| `article_type` | `keyword` | 문서 유형 패싯. 예를 들어 인물, 장소, 사건·대회 |
| `embedding` | `dense_vector` | 본문을 벡터 검색에 쓸 수 있도록 저장 |

`queries.jsonl`과 `qrels.jsonl`은 이후 평가에서 사용합니다. 색인할 때 문단 ID를 유지하면 검색 결과를 qrels의 `docid`와 연결할 수 있습니다.

[제목별 분류표](dataset/facets-by-title.json)에서 `topic`과 `article_type`을 가져옵니다.

## 2. Kibana에서 문단 한 건 색인하기

매핑을 확인하는 예시이므로 벡터는 손으로 적은 3차원 값입니다.

```http
PUT /rag-indexing-demo
{
  "mappings": {
    "properties": {
      "docid": { "type": "keyword" },
      "title": { "type": "text" },
      "text": { "type": "text" },
      "source": { "type": "keyword" },
      "embedding": { "type": "dense_vector", "dims": 3, "similarity": "cosine" }
    }
  }
}

PUT /rag-indexing-demo/_doc/course-change-01?refresh=wait_for
{
  "docid": "course-change-01",
  "title": "수강 정정 안내",
  "text": "수강 정정 기간에는 신청 과목을 변경할 수 있다.",
  "source": "가상 학사 안내",
  "embedding": [0.1, 0.2, 0.3]
}

GET /rag-indexing-demo/_doc/course-change-01
GET /rag-indexing-demo/_mapping
GET /rag-indexing-demo/_count
```

`_doc` 응답에서 본문과 출처를 확인하고, `_mapping`에서 벡터 차원이 `3`인지 봅니다. 같은 `_id`로 본문을 바꿔 다시 색인한 뒤 `_count`가 여전히 `1`인지 확인합니다. [Elasticsearch Index API](https://www.elastic.co/guide/en/elasticsearch/reference/8.19/docs-index_.html)

## 3. 실제 임베딩을 생성해 문단 색인하기

e5-small 모델을 이용하여 색인합니다. 첫 실행은 모델을 내려받습니다. 차원은 384차원입니다
[모델 카드](https://huggingface.co/intfloat/multilingual-e5-small)

강의 폴더의 [index_miracl.py](index_miracl.py)를 저장소 루트에서 실행합니다. 실습 계정에는 대상 인덱스를 생성하고 문서를 쓰고 읽을 권한이 필요합니다.

```powershell
uv run --python 3.12 --with 'elasticsearch>=8.19,<9' --with sentence-transformers python ./10_14_1106_1127_retrieval/index_miracl.py --limit 10
```

스크립트는 자기 위치에서 `dataset/corpus.jsonl`과 `dataset/facets-by-title.json`을 읽고, 기본값으로 `rag-miracl-ko-e5-small`에 색인합니다. 다른 경로나 인덱스가 필요하면 각각 `RAG_CORPUS_PATH`와 `RAG_ES_INDEX`를 지정합니다. 접속 주소와 계정, 인증서 검증 설정은 Python 기초 실습과 같은 값을 사용합니다.

```python
import argparse
import json
import os
from itertools import islice
from pathlib import Path

from elasticsearch import Elasticsearch, helpers
from sentence_transformers import SentenceTransformer

ES_URL = "https://localhost:9200"
ES_USERNAME = "elastic"
ES_PASSWORD = "elastic"

parser = argparse.ArgumentParser()
parser.add_argument("--limit", type=int, help="색인할 최대 문단 수")
parser.add_argument("--offset", type=int, default=0, help="앞에서 건너뛸 문단 수")
args = parser.parse_args()
if args.offset < 0 or (args.limit is not None and args.limit < 1):
    parser.error("--offset은 0 이상, --limit은 1 이상이어야 합니다.")

index = os.getenv("RAG_ES_INDEX", "rag-miracl-ko-e5-small")
default_corpus = Path(__file__).resolve().parent / "dataset" / "corpus.jsonl"
corpus = Path(os.getenv("RAG_CORPUS_PATH", str(default_corpus)))
facets_by_title = json.loads(corpus.with_name("facets-by-title.json").read_text(encoding="utf-8"))
with corpus.open(encoding="utf-8") as stream:
    end = None if args.limit is None else args.offset + args.limit
    passages = [json.loads(line) for line in islice((line for line in stream if line.strip()), args.offset, end)]
if not passages:
    parser.error("지정한 범위에 색인할 문단이 없습니다.")

model_name = "intfloat/multilingual-e5-small"
model = SentenceTransformer(model_name)
vectors = model.encode(
    [f"passage: {item['text']}" for item in passages],
    batch_size=16,
    normalize_embeddings=True,
    show_progress_bar=True,
)

with Elasticsearch(
    ES_URL,
    basic_auth=(ES_USERNAME, ES_PASSWORD),
    verify_certs=False,
    ssl_show_warn=False,
) as client:
    extra_fields = {
        "chunk_index": {"type": "integer"},
        "topic": {"type": "keyword"},
        "article_type": {"type": "keyword"},
    }
    if not client.indices.exists(index=index):
        client.indices.create(
            index=index,
            mappings={
                "_meta": {"embedding_model": model_name},
                "properties": {
                    "docid": {"type": "keyword"},
                    "title": {"type": "text"},
                    "text": {"type": "text"},
                    "source": {"type": "keyword"},
                    **extra_fields,
                    "embedding": {
                        "type": "dense_vector",
                        "dims": 384,
                        "similarity": "cosine",
                    },
                },
            },
        )
    else:
        client.indices.put_mapping(index=index, properties=extra_fields)

    actions = (
        {
            "_index": index,
            "_id": item["docid"],
            "_source": {
                **item,
                "chunk_index": int(item["docid"].rsplit("#", 1)[1]),
                "source": "MIRACL Korean / Wikipedia",
                **facets_by_title[item["title"]],
                "embedding": vector.tolist(),
            },
        }
        for item, vector in zip(passages, vectors, strict=True)
    )
    indexed, _ = helpers.bulk(client, actions, refresh="wait_for")
    print(f"색인 처리 {indexed}건 · 인덱스 {index}")
    print(f"확인용 첫 문단 ID: {passages[0]['docid']}")
```

첫 10건이 확인되면 아래 명령으로 **11~20번째 문단만** 추가 색인합니다. `--offset 10`은 앞의 10건을 건너뛴다는 뜻입니다.

```powershell
uv run --python 3.12 --with 'elasticsearch>=8.19,<9' --with sentence-transformers python ./10_14_1106_1127_retrieval/index_miracl.py --offset 10 --limit 10
```



## 4. 색인 결과 확인

```http
GET /rag-miracl-ko-e5-small/_count
GET /rag-miracl-ko-e5-small/_mapping
GET /rag-miracl-ko-e5-small/_search
{
  "size": 1,
  "_source": ["docid", "chunk_index", "title", "text", "source", "embedding"],
  "query": { "match_all": {} }
}
```

- 새 실습 인덱스의 문서 수가 첫 실행 후 **10건**, 두 번째 실행 후 **20건**인지 확인합니다.
- 문단 한 건을 골라 `_id`와 `docid`가 같은지, 제목·본문·출처가 들어 있는지 확인합니다.
- `_mapping`에서 `embedding`이 `dense_vector`, `dims`가 `384`인지 확인합니다.

두 패싯에 어떤 값이 들어갔는지 확인합니다. 아래 요청은 각 값에 속하는 **문단 수**를 보여줍니다.

```http
GET /rag-miracl-ko-e5-small/_search
{
  "size": 0,
  "aggs": {
    "topics": { "terms": { "field": "topic" } },
    "article_types": { "terms": { "field": "article_type" } }
  }
}
```
