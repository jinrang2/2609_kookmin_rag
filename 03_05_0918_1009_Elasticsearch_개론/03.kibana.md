# term_match_index 예제

1. 인덱스 초기화

```json
DELETE term_match_index?ignore_unavailable=true
```

```json
PUT term_match_index
```

2. 문서 생성

```json
PUT term_match_index/_doc/1
{
  "contents": "beautiful day"
}
```

3. 문서 조회

```json
GET term_match_index/_doc/1
```

4. 매핑 조회

```json
GET term_match_index/_mapping
```

5. 텍스트 분석

```json
POST term_match_index/_analyze
{
  "field": "contents",
  "text": "beautiful day"
}
```

```json
POST term_match_index/_analyze
{
  "field": "contents",
  "text": "Beautiful Day!"
}
```

6. Term Vector 조회

```json
GET term_match_index/_termvectors/1
{
  "fields": [
    "contents",
    "contents.keyword"
  ],
  "field_statistics": false,
  "term_statistics": false,
  "positions": true,
  "offsets": true
}
```

contents 필드의 색인 내용
```
contents (text 역색인)
├─ beautiful → 문서 1, position 0
└─ day       → 문서 1, position 1
```

contents.keyword 필드의 색인 내용
```
contents.keyword (keyword 역색인)
└─ beautiful day → 문서 1
```
