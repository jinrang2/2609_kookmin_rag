# 템플릿

인덱스 조회
```json
GET _cat/indices/*,-.*?v=true&s=index&h=index,status,docs.count
```

템플릿 생성
```json
PUT _index_template/test_template
{
  "index_patterns": [
    "test_*"
  ],
  "template": {
    "settings": {
"number_of_shards": 3,
"number_of_replicas": 1
},
    "mappings": {
      "properties": {
        "name": {
          "type": "text"
        },
        "age": {
          "type": "short"
        },
        "gender": {
          "type": "keyword"
        }
      }
    }
  }
}
```

템플릿 적용

템플릿이 적용된 인덱스 생성
```json
PUT test_index1/_doc/1
{
  "name": "kim",
  "age": 10,
  "gender": "male"
}
```

템플릿이 적용되지 않은 인덱스 생성
```json
PUT train_index1/_doc/1
{
  "name": "kim",
  "age": 10,
  "gender": "male"
}
```
맵핑과 다른 타입으로 입력시 오류 발생
```json
PUT train_index1/_doc/1
{
"name":"lee",
"age":"19 years"
}
```

템플릿 삭제
```json
DELETE _index_template/test_template
```

다이내믹 템플릿
```json
PUT dynamic_index1
{
  "mappings": {
    "dynamic_templates": [
      {
        "my_string_fields": {
          "match_mapping_type": "string",
          "mapping": {
            "type": "keyword"
          }
        }
      }
    ]
  }
}
```
다이내믹 맵핑이 적용된 인덱스에 색인

```json
PUT dynamic_index1/_doc/1
{
  "name": "mr.kim",
  "age": 40
}
```

match unmatch 조건문을 활용한 다이내믹 템플릿
```
PUT dynamic_index2
{
  "mappings": {
    "dynamic_templates": [
      {
        "my_long_fields": {
          "match": "long_*",
          "unmatch": "*_text",
          "mapping": {
            "type": "long"
          }
        }
      }
    ]
  }
}
```

match  unmatch 다이내믹 템플릿 색인
```json
PUT dynamic_index2/_doc/1
{
  "long_num": "5",
  "long_text": "170"
}
```


# 분석기

기본 분석 API

```json
POST _analyze
{
"analyzer": "stop",
"text":"The 10 most loving dog breeds"
}
```

확장 분석 API
```json
POST _analyze
{
  "analyzer": "stop",
  "text": "The 10 most loving dog breeds",
  "explain" : true
}
```

이메일 토크나이저 
```json
POST _analyze
{
  "tokenizer": "uax_url_email",
  "text": "email: elastic@elk-company.com"
}
```

커스텀 분석기
```json
PUT customer_analyzer
{
  "settings": {
    "analysis": {
      "filter": {
        "my_stopwords": {
          "type": "stop",
          "stopwords": [
            "lions"
          ]
        }
      },
      "analyzer": {
        "my_analyzer": {
          "type": "custom",
          "char_filter": [],
          "tokenizer": "standard",
          "filter": [
            "lowercase",
            "my_stopwords"
          ]
        }
      }
    }
  }
}
```


커스텀 분석기 적용 인덱스로 분석
```
GET customer_analyzer/_analyze
{
  "analyzer": "my_analyzer",
  "text": "Cats Lions Dogs"
}
