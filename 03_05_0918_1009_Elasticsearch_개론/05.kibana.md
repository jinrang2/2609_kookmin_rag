## 평균 집계
```json
GET kibana_sample_data_ecommerce/_search
{
  "size": 0,
  "aggs": {
    "stats_aggs": {
      "avg": {
        "field": "products.base_price"
      }
    }
  }
}
```

## base_price의 25%에 해당하는 값 50%에 해당하는 값
```json
GET kibana_sample_data_ecommerce/_search
{
  "size": 0,
  "aggs": {
    "stats_aggs": {
      "percentiles": {
        "field": "products.base_price",
        "percents": [
          25,
          50
        ]
      }
    }
  }
}

## day_of_week의 유니크한 값 개수
```json
GET kibana_sample_data_ecommerce/_search
{
  "size": 0,
  "aggs": {
    "carid_aggs": {
      "cardinality": {
        "field": "day_of_week",
        "precision_threshold": 100
      }
    }
  }
}
```

## cardinality는 정확하지 않다
```json
GET kibana_sample_data_ecommerce/_search

  "size": 0,
  "aggs": {
    "cardinality_low": {
      "cardinality": {
        "field": "order_id",
        "precision_threshold": 1
      }
    },
    "cardinality_default": {
      "cardinality": {
        "field": "order_id"
      }
    },
    "cardinality_high": {
      "cardinality": {
        "field": "order_id",
        "precision_threshold": 40000
      }
    },
    "distinct_order_ids": {
      "terms": {
        "field": "order_id",
        "size": 10000,
        "shard_size": 10000
      }
    }
  }
}
```

## 검색 쿼리와 집계 쿼리를 같이 사용
```json
GET kibana_sample_data_ecommerce/_search
{
  "size": 0,
  "query": {
    "term": {
      "day_of_week": "Monday"
    }
  },
  "aggs": {
    "query_aggs": {
      "sum": {
        "field": "products.base_price"
      }
    }
  }
}
```
